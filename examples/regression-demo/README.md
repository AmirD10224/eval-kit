# Example: a regression that gets auto-rejected

This is the marquee demo, what happens in CI when a prompt change causes a
regression EvalKit can detect. It's also the source of the screenshot
embedded in the project README.

## What's in here

- `golden.jsonl`. 30-row faithfulness golden set with two human raters per
  row.
- `rubrics/faithfulness.yaml`, calibrated faithfulness rubric.
- `suite.yaml`, three metrics: judge faithfulness, regex `idk_when_no_ctx`,
  exact-match `closed_book`.
- `app.py`, toy RAG QA app you'd modify in a PR to introduce a regression.
- `baseline.json` / `current.json`, pre-computed reports showing
  faithfulness drop **−13.4pp** (0.847 → 0.713). The numbers in these JSONs
  are illustrative, running `evalkit run` on the live `app.py` produces
  metric scores that depend on the judge model.
- `render_screenshot.py`, runs `evalkit diff` and renders the resulting
  PR-comment Markdown to a PNG, written to
  `docs/screenshots/auto-reject.png`.
- `expected_pr_comment.md`, the exact Markdown the diff would post; this
  file is regenerated by `render_screenshot.py`.

## Run the diff (terminal output, exit code)

```bash
cd examples/regression-demo
evalkit diff \
    --baseline baseline.json \
    --current current.json \
    --threshold 5
# exit code: 1 (regression detected)
```

## Render the auto-reject screenshot

```bash
pip install "evalkit-oss[render]"
playwright install chromium    # one-time
python render_screenshot.py
# wrote: docs/screenshots/auto-reject.png
```

> ⚠ The PNG is a Playwright-rendered facsimile of a GitHub PR comment, not a
> screenshot of a live PR. It's the marketing asset shown in the README.
> See `docs/guides/real-pr-demo.md` for the 10-minute walkthrough that
> captures a real PR screenshot using this same suite.

## Run the suite live (with `--stub` for offline mode)

```bash
cd examples/regression-demo
python app.py > predictions.jsonl
evalkit run \
    --suite suite.yaml \
    --predictions predictions.jsonl \
    --stub \
    --output run.json
```
